# OKF Interview Lab

Адаптивный демонстрационный опрос для исследования того, как люди сохраняют важный контекст работы.

**Открыть демо:** https://kokolsk1y.github.io/okf-interview-lab/

Опрос работает целиком в браузере. Ответы сохраняются только в `localStorage` на устройстве участника; после завершения их можно скачать в JSON. Серверной базы ответов нет, поэтому очистка данных браузера удалит локальные ответы.

## Проверка

```sh
npm test
```

Сайт публикуется из корня ветки `main` через GitHub Pages. В репозитории находятся только файлы этого демо.
