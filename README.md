# OKF Interview Lab

Адаптивный демонстрационный опрос для исследования того, как люди сохраняют важный контекст работы.

**Открыть демо:** https://kokolsk1y.github.io/okf-interview-lab/

Опрос работает в браузере. После завершения он отправляет выбранные варианты и полные текстовые ответы в закрытую Google Таблицу организатора через Google Apps Script. Участник также может скачать свой ответ в JSON. До завершения опроса ответы остаются в `localStorage` на его устройстве.

Публичный адрес приёма не проверяет личность участника, поэтому в таблицу могут попасть повторные или посторонние записи. Синтетические демонстрационные ответы хранятся отдельно и не входят в показатели реальных прохождений.

## Проверка

```sh
npm test
```

Сайт публикуется из корня ветки `main` через GitHub Pages. В репозитории находятся только файлы этого демо.
